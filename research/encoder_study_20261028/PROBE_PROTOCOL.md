# Frozen-feature orientation probe

Supporting diagnostic added while measurement jobs were running, before inspecting probe outcomes. This does not change the frozen encoders or the primary experiment.

Question: can a small supervised readout recover within-object orientation from clean, globally pooled encoder features, beyond a per-object constant orientation baseline?

For each shared stage, each of four primary network variants, and each object, use the 20 development frames to fit ridge regression from pooled features to the nine rotation-matrix entries. Standardize each feature using development training fold statistics only. Select alpha from [0.01, 0.1, 1, 10, 100, 1000] using fixed five-fold development CV and rotation-entry mean squared error. Refit on all development data, project outputs to SO(3) with SVD, and evaluate once on the 20 held-out frames. Fit a constant chordal-mean rotation baseline from development GT. Include three development-label permutation controls per model with independently repeated development-only alpha selection. Average permutation controls per held-out frame; they do not create extra samples.

Report object-macro mean/median raw geodesic error and error minimized over identity plus annotated discrete rotation symmetries. Reject continuous symmetries rather than inventing a discretization. Symmetry translations are irrelevant to this orientation-only metric; this is not a model-surface pose metric. Discrete annotations are approximately rotational and are projected onto SO(3) before geodesic evaluation. Report paired frame-stratified bootstrap changes against the constant baseline. Do not claim a general pose-estimation result, unseen-object generalization, or significance from exploratory multiple comparisons.

Inputs use GT-aligned crops and existing diagnostic splits. GT is not an explicit feature but influences crop centering (including the rotated CAD bounding-box center), scale, and XYZ normalization. This may simplify the decoding task; it is not a blind registration experiment. The probe is object-specific and uses only 20 training images per object. Close sequence frames and backgrounds are confounds. A good result means some orientation information is decodable in this setting; a poor result does not show the full spatial encoder or actual pair-comparison network lacks pose information. Global pooling discards spatial information.
