# Robust BOP encoder follow-up

Goal: test whether symmetry supervision, geometric structure and appearance supervision improve the FoundationPose refinement encoder under imperfect observations. No claim of improvement before evaluation.

All previous experiments remain untouched. BOP LINEMOD official test sequences are repurposed for local development; these are NOT official benchmark results or verified unseen-to-pretraining data. Previously inspected objects and frames make all outcomes exploratory.

Use existing real RGB-D geometry cache (120 sampled frames/object, 96 pixels) and corrected vertex-color rotation cache (240 frames/object, 48 training-only rendered references). Shared temporal partition based on each full scene's chronological frame rank: train <60%, development 65–80%, evaluation >=85%; buffers discarded. Geometry objects 3/7 excluded from training, evaluated separately as previously inspected adaptation-excluded objects. Rotation bank references filtered to this same training partition. No cross-task training/development overlap. Save exact manifests and check disjointness before training.

Matched seeds 42/123/2026, 3000 steps, batch 8. Arms: frozen encoder with trained decoders; geometry only; geometry + symmetry; geometry + texture; all three. Geometry predicts missing CAD depth and normals from real RGB and incomplete measured XYZ. Texture predicts RGB high-frequency residuals on randomly hidden RGB patches, with XYZ removed at those patches, using spatial features without input skip connections. This encourages local appearance information; it does not prove semantic texture understanding. Symmetry uses pose-distance soft labels against corrected textured CAD references, accepting BOP discrete equivalent rotations. Geometric symmetries can disagree with visible texture; report that limitation.

All adapted arms keep batch-normalization statistics fixed and use a small normalized-feature anchor to original weights. Same per-step sampled geometry batch across arms; deterministic corruption across seeds/arms. Original teacher is frozen. Encoder LR 1e-5, decoder LR 1e-3, AdamW, clipping 5. Loss: depth + .2 normal; appearance arms add .2 RGB residual L1; symmetry arms add .1 matching cross entropy; adapted arms add .01 feature anchor. No tuning on evaluation.

Select minimum development normalized depth MAE + .2 × normal angle / 180, identical criterion across arms (texture/rotation are secondary). Checkpoints include optimizer/RNG states every 100 steps and best model, allowing restart. Evaluate geometry on clean-RGB, grayscale-RGB, occluded-RGB and extra XYZ dropout conditions; all start from existing 40% missing-depth/2mm noise cache, so 'standard' is already corrupted. Report normal error, depth mm, texture residual error and per-object paired results; no independent-frame significance claims.

After training, queue full FoundationPose registration for original plus each adapted arm/seed on fixed four evaluation frames each of objects 5/8/9/10/11. Conditions: observed input; added 5mm depth noise; 40% block depth dropout; grayscale RGB. Fixed seeds, GT visible masks, original scoring network and pose heads, only refinement encodeA replaced. Report ADD and nearest-neighbor ADD-S separately and recall below 10% diameter; no GT-based pose initialization/selection. Small diagnostic with known identity/GT masks, not detector-to-pose deployment benchmark. Save input images and predictions. Resumable per-case records. Main question: does the combined encoder improve pose accuracy on corrupted input without degrading observed input? Report all outcomes including failures.
