# RGB-D geometry completion and normal supervision — follow-up fixed before training

Hypothesis: the previous RGB-only depth task mismatched FoundationPose's RGB-XYZ interface, and raw sensor depth made poor local shape targets. Retaining partial XYZ context and supervising missing patches with CAD-rendered geometry may provide a more useful geometric objective. These are hypotheses, not diagnosed causes of the prior null result.

Use actual BOP LINEMOD RGB, measured depth, intrinsics, visible masks, object models and object-to-camera poses. Render clean depth in the identical GT-derived crop. Retain pixels inside the annotated visible object where measured depth agrees with CAD depth within max(15 mm, 5% diameter). Reject unstable finite-difference normal neighborhoods. Rendering is label generation, never an encoder input. Cropping uses GT visible object bounds: diagnostic, not blind deployment.

Sample 120 frames/object, 96x96 crops. Train objects 1,2,4,5,6,8,9 (first 70% sampled frames). Omit next 10% temporal buffer. Development objects 10,11 select checkpoints. Previous evaluation objects 12,13,14,15 are now EXPLORATORY only. Objects 3 and 7 were excluded from the earlier adaptation experiment; reserve their geometry-completion performance until all training and checkpoint selection finish. They are held out from these adaptation runs, not verified unseen to pretrained FoundationPose or older unrelated local studies. Official LM test sequences are being repurposed for development, not official benchmark reporting.

Inputs: RGB in [0,1] plus observed camera XYZ normalized by object radius. A deterministic 8x8-grid patch mask with 40% block probability hides geometric input; RGB stays visible. Geometric centering comes only from the remaining visible measured XYZ, not CAD/GT pose. Add deterministic 2 mm noise to retained measured depth. XYZ is zero for holes/background/invalid measurements. Model must predict relative CAD depth and camera surface normals in held-out patches. Evaluate only held-out valid depth/normal pixels. Target relative depth is CAD Z minus observed-context median Z, divided by diameter. Diameter is known CAD metadata; no target geometric information sets the context center. Store masks and paired targets for audit.

Arms, seeds 42,123,2026, matched batches/decoder initialization:
- frozen: pretrained shared encoder fixed; train depth+normal decoder.
- depth: fine-tune encoder at lr 3e-5, train decoder at 1e-3; depth loss + .01 normalized-feature anchor to original pretrained encoder.
- normal: same as depth, add 0.2 cosine surface-normal loss.
All decoders have identical depth+normal architecture. Frozen arm trains both outputs, providing a strong baseline. Optimize 1500 steps, batch 16, AdamW weight decay 1e-4, norm clip 5, frozen BN running statistics, matched RGB brightness/contrast augmentation. Validate every 250 steps. Select minimum macro development normalized masked-depth MAE; report normal angle as secondary. No selection on exploratory or newly held-out objects.

After adaptation, freeze all selected encoders and fit fresh depth+normal decoders with identical initialization, 500 steps, validation every 100 steps. Baseline fresh readout uses the original encoder. This tests usefulness beyond decoder co-adaptation. Primary outcome: object-macro normalized masked-depth MAE on reserved objects 3,7. Report mm MAE, median angular error per image averaged by object, explored objects separately, seen temporal performance, paired results and seed variation. Compare constant relative-depth and observed-only inpainting controls. Three seeds/two reserved objects provide limited generalization evidence; no independent-frame significance claims.
