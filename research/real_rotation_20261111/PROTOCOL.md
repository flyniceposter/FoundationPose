# Real-image BOP rotation, symmetry and texture study

Uses real BOP LINEMOD RGB photographs as queries. CAD renders are references only. Objects 5 (can),8 (driller),9 (duck),10 (eggbox),11 (glue). The last two have BOP annotated discrete symmetry. This is a diagnostic using GT visible masks/crops and known object identity, not detection or full 6D pose estimation.

Per object sample 240 evenly spaced sequence frames. Train first 60%, omit next 5%, development next 15%, omit next 5%, evaluate last 15%. References are 48 fixed training poses, selected evenly through training frames. No evaluation/development pose is inserted into the bank. Thus there is a nonzero oracle rotation error determined by bank coverage. Queries use RGB/255 with XYZ zero; background outside visible GT mask is replaced by constant 40/255. Reference crops use each training frame's K, GT pose and crop window. The bank is fixed for pretrained and adapted arms.

Compare pretrained original encoder, ordinary rotation fine-tuning and symmetry-aware fine-tuning, seeds 42,123,2026. Same initial encoder, minibatch order, RGB brightness/contrast augmentations, lr 1e-5, AdamW weight decay 1e-4, clip 5, 1500 steps, batch 8. Descriptor is adaptive 4x4 average pooling of shared CNN output and L2 normalization, cosine logits/0.07. Ordinary soft targets weight references by exp(-angle^2/(2*15deg^2)); symmetry-aware targets minimize angular error over BOP's equivalent rotations before weighting. Add 0.01 normalized feature anchor to frozen pretrained descriptor to limit drift. Preserve BN statistics. Select checkpoint every 250 steps by mean object-macro symmetry-aware development rotation error with textured references. All evaluation occurs after selections are fixed. Ordinary and symmetry-aware arms share selection metric so neither gets a test advantage.

Metric: object-macro geodesic rotation error (raw and minimized over BOP discrete rotational symmetries), recall <=30deg, oracle reference-bank error, and excess over oracle. These are rotation diagnostics, not BOP MSSD/VSD/MSPD or pose AR. For rotation-only metrics, extract the rotation from full annotated symmetry transforms, project approximately orthogonal rotations onto SO(3), and do not use those approximations as full pose equivalences. Continuous symmetries are unsupported and rejected for selected objects.

Texture ablation: real queries remain real and unchanged; render the same training-pose bank once with original vertex colors and once with uniform material color. Identical depth buffers must match. This is a reference-appearance shift; a gap is evidence of reliance on matching appearance, not proof that fine-tuning newly learned texture or that labels alone explain it. No synthetic 'texture-free real photograph' is claimed. Report all objects and all seeds, including non-symmetric controls. Original pretrained matching is mandatory: ceiling performance or no adaptation advantage is an informative result.

All LM official test sequences are reused as development research. Temporal blocks share scenes; no independent-scene generalization, original-pretraining exclusion or official benchmark claim. Masked backgrounds, rendered materials, mesh registration and incomplete reference coverage can limit retrieval. Save real originals, encoder inputs, reference banks, poses, scores, checkpoint histories, per-image metrics and fixed example figures (first evaluation query/object, not cherry-picked). Include the earlier mustard demo as a separate illustration with its actual provenance.
